# ASPHALT V5 — أسفلت V5

تطبيق Android أصلي (Kotlin + Jetpack Compose) لقراءة بيانات عروض الرحلات المدعومة وعرض تقييم فوري للسائق.

## ما يتضمنه هذا الإصدار
- اسم العرض ASPHALT V5 مع الاحتفاظ بمعرّف التطبيق الحالي لتسهيل التحديث فوق النسخة السابقة وعدم تغيير مساحة بيانات التطبيق.
- أصول الهوية البصرية الأصلية المرفقة من المستخدم، دون إعادة رسم حروف الشعار.
- لوحة ألوان مستوحاة من الشعار الأحمر/السماوي في الوضعين النهاري والليلي.
- إعداد قابل للتبديل بين احتساب مسافة الرحلة فقط واحتساب المسافة الكاملة (الاستلام + الرحلة).
- الاحتفاظ بخدمات القراءة وإمكانية الوصول وOCR والكارت العائم وقواعد السائق الحالية.

## بناء APK
يُبنى APK تجريبي عبر GitHub Actions عند الدفع إلى `main` أو `master` أو عبر `workflow_dispatch`. الملف الناتج يظهر في Artifacts باسم `asphalt-v5-debug-apk`.

## ملاحظات مهمة
- هذا المشروع لا يقبل الرحلات ولا يضغط أزرار تطبيقات النقل؛ القراءة والتقييم فقط.
- لا تعتبر نتائج OCR مؤكدة إذا كانت بيانات الرحلة غير واضحة؛ يجب التحقق من طلبات حقيقية قبل الاعتماد أثناء القيادة.
- معرّف الحزمة بقي كما في المشروع الأصلي عمدًا، للحفاظ على التوافق مع بيانات التطبيق والتحديثات.
